# Project overview

- **Voicely Local** is a privacy-first, local desktop voice-writing assistant inspired by Typeless-style workflows.
- The app runs as a **Tauri 2** desktop application with a **React 18 + TypeScript + Vite** frontend and a **Rust** native backend.
- Speech recognition uses a bundled local Whisper model. Text rewriting uses optional locally downloaded GGUF models through an isolated LLM worker.
- Treat all dictated audio, transcripts, history, model paths, and user preferences as sensitive local data. Do not add cloud uploads, telemetry, or external text-processing APIs without an explicit product decision.

# Important paths

- `src/App.tsx` — primary application UI, recording workflow, settings, model manager, history, and Tauri event handling.
- `src/Onboarding.tsx` — first-run onboarding, permissions, shortcut configuration, and initial model choice.
- `src/DictationOverlay.tsx` — separate floating dictation overlay window.
- `src/audio.ts` — browser/WebView microphone capture, PCM/WAV encoding, audio level, silence detection, and constraints.
- `src/text.ts` — deterministic local text cleanup; keep it content-preserving.
- `src/history.ts` — local-only dictation history persistence and retention limits.
- `src/styles.css` — shared main-window and overlay styling.
- `src-tauri/src/lib.rs` — Tauri commands, local model download/validation, worker lifecycle, overlay, macOS paste automation, and system checks.
- `src-tauri/src/bin/whisper-worker.rs` — isolated Whisper worker. Keep Whisper dependencies out of the main process.
- `src-tauri/src/bin/llm-worker.rs` — isolated Metal/llama.cpp worker for GGUF text models.
- `src-tauri/resources/models/ggml-small.bin` — bundled Whisper Small default model.
- `src-tauri/binaries/` — architecture-qualified packaged worker binaries generated by `prepare:workers`; do not edit manually.
- `src-tauri/tauri.conf.json` — Tauri build, resource bundle, worker, window, and macOS configuration.
- `src-tauri/Info.plist` — macOS permission descriptions, including microphone access.

# Development commands

- Install frontend dependencies: `npm install`
- Check/build frontend: `npm run build`
- Prepare and SHA-256 validate the bundled Whisper Small model: `npm run prepare:models`
- Build both native workers into `src-tauri/binaries`: `npm run prepare:workers`
- Start desktop development: `npm run tauri dev`
- Check Rust main app: `cargo check --manifest-path src-tauri/Cargo.toml`
- Check Whisper worker: `cargo check --manifest-path src-tauri/Cargo.toml --features whisper-worker --bin whisper-worker`
- Check LLM worker: `cargo check --manifest-path src-tauri/Cargo.toml --features llm-worker --bin llm-worker`
- Create macOS release bundle/DMG: `npm run tauri build`

# Native architecture conventions

- Keep `whisper-rs` and `llama-cpp-2` isolated in their respective worker binaries. Do **not** add both to the main Tauri process; they can link duplicate ggml symbols.
- The main process communicates with workers through temporary files, stdout/stderr, Tauri events, and process IDs. Preserve request IDs so streamed output and cancellation cannot affect another request.
- Worker binaries must be built for the target architecture and bundled as resources. Any release packaging change must verify that the workers are executable inside `.app`.
- macOS auto-paste requires Accessibility permission. Do not present it as available unless the local system-status check confirms permission.
- The macOS deployment target is 11.0. Preserve this when changing native build configuration.

# Model and download rules

- Whisper Small is the bundled fallback/default model. Optional models must be explicit user downloads.
- Downloads must be resumable, cancellable, atomically finalized (`.part` then rename), and validated before activation.
- Use SHA-256 validation for downloaded GGUF models. Never activate a model that is incomplete or fails validation.
- Active model IDs are local preferences. On failed download, cancellation, deletion, or validation failure, retain the previous active model.
- Do not silently download multi-gigabyte models. Always require a user action and show the local size/progress.

# Frontend conventions

- Use strict TypeScript; keep Tauri payloads typed and use camelCase on the frontend.
- Persist non-sensitive UI preferences locally. Avoid recording audio in history; history may contain only user-visible text and metadata.
- Microphone constraints, selected input device, push-to-talk behavior, and silence detection must fail safely to system defaults.
- Keep auto-stop disabled for push-to-talk. The default silence timeout is 12 seconds and must remain user-configurable.
- Any action that replaces editor text should preserve the original text until local streaming completes, so cancellation/error recovery can restore it.

# Validation before handoff

- Run `npm run build` after frontend changes.
- Run the relevant `cargo check` commands after Rust or worker changes.
- Run `git diff --check` before handoff.
- For packaging-related changes, build a release and verify `codesign --verify --deep --strict` on the app bundle plus the presence/executability of bundled workers.
- The current DMG can be ad-hoc signed for local testing. Public macOS distribution additionally requires Developer ID signing and Apple notarization.
