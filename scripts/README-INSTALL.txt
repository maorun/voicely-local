VOICELY LOCAL — INSTALLATION

1. Doppelklicke auf „Install Voicely Local“.
2. Voicely wird nur für dich nach ~/Applications installiert.
3. Der Applications-Ordner wird danach automatisch geöffnet.
4. Starte Voicely Local aus ~/Applications.

Für die Diktatfunktion benötigt Voicely beim ersten Start Mikrofonzugriff.
Für automatisches Einfügen wird zusätzlich die Freigabe unter
Systemeinstellungen → Datenschutz & Sicherheit → Bedienungshilfen benötigt.

Alle Sprach- und Textverarbeitung erfolgt lokal auf diesem Mac.
